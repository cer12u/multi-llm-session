# チャット中心のセッションUI

専用Webアプリであり、外部Slack/Discordではありません。表示の成功は実LLM品質の証拠ではありません。

左の一覧からセッションを作成・選択し、中央の公開履歴と下の入力欄を使います。作成だけでは推論しません。Enter送信、Shift+Enter改行、IME中Enter抑止に対応します。返信は同じ公開会話へ保存され、全Agentへ配送されます。

## 履歴・下書き

履歴・検索・スレッドには追加ページ取得があります。履歴200件/検索50件は初回取得の単位で、完全な過去履歴への到達を制限する上限ではありません。古い原文へのリンク、読み位置の保持、再接続時の編集・削除再照合を扱います。過去を読んでいる間は末尾へ強制移動しません。詳細はARCHIVE_NAVIGATION.mdを参照してください。

下書きはセッション・返信元別にIndexedDBへ保存し、再読込/タブを閉じた後も復元します。送信結果不明の元payload/キーを改稿と分離し、結果確認または同じキーでの再送を使います。ログアウト時に端末内の保存を消去します。スクロール位置は同じタブ内だけの保持です。詳細はDURABLE_DRAFTS.mdを参照してください。

## 管理

参加者、定義/Provider、資料、実行設定、私有診断、運用予算は管理者のパネルに分離します。人格版の適用と個体の置換を区別し、DRAFT/PAUSEDで明示操作します。資料の版・対象、非応答の理由、復旧操作は会話本文と混ぜません。

予算保存・予算更新・再開は別操作です。自動更新は明示opt-inだけです。未投稿候補・私有状態・persona・秘密資料・モデルキーを閲覧者へ配信しません。ログアウト後の遅延応答が次の利用者へ表示されないよう世代を検証します。

## 検証と範囲

追加E2Eは実Core/Worker/HTTP/SQLiteとブラウザーを使います。外部モデルだけを合成応答へ置換できますが、自然な会話品質とは別です。IMEイベントは合成試験で、全OS/入力方式の実機検証ではありません。

狭い画面では一覧をドロワー、右パネルを全面表示にします。DM・添付・音声・リアクション・外部renderer・複数人ユーザーACL・永続未読は初期範囲外です。
