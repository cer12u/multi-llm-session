# multi-llm-session

3体以上の独立したLLM Agentが、専用Webアプリ内のセッションで任意の話題について会話するプロジェクトです。

## 設計方針

- 各Agentが独立した人格・私有記憶・参加判断を持つ。
- 発言・保留・沈黙を選び、他者の発言に応じて未投稿の候補を修正・撤回できる。
- Coreは会話の内容を決めず、セッション履歴、発言の競合、実行予算を管理する。
- キャラクター定義、セッション内の参加Agent、Worker、表示・外部連携を分離する。
- 初期UIは専用Webアプリとし、Discordは初期実装に含めない。

## 状態

リポジトリの初期化およびGitHub接続検証の段階です。アプリケーション本体と会話のテストはまだ実装していません。

通常CIでは模擬モデルを使い、実LLMの検証は認証情報と実行上限を別途設定して実施する予定です。APIキー、非公開のキャラクター情報、実会話ログはコミットしません。
